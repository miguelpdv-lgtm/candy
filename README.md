# Candy Lab — landing

Landing de Candy Lab, dulcería americana en Barranquilla con envíos a toda Colombia. HTML, CSS y JavaScript sin dependencias, publicada con GitHub Pages: https://miguelpdv-lgtm.github.io/candy/

- `index.html`: la página.
- `assets/styles.css`: estilos. Los colores salen del logo (rosa chicle, cherry y crema) más regaliz para el texto.
- `assets/main.js`: menú móvil, cinta animada y carrito de demostración. Pon el número de la tienda en `WHATSAPP` para activar los enlaces.
- `assets/fonts/`: Fraunces (títulos) y DM Sans (texto), licencia OFL.
- `assets/img/`: logo y fotos de demostración de Unsplash. Hay que cambiarlas por fotos propias de los productos.

Para verla en local: `python3 -m http.server` y abre http://localhost:8000.
