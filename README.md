# Candy Lab — landing

Landing de Candy Lab, dulcería americana en Barranquilla con envíos a toda Colombia. HTML, CSS y JavaScript sin dependencias, publicada con GitHub Pages: https://miguelpdv-lgtm.github.io/candy/

- `index.html`: la página.
- `assets/styles.css`: estilos. Colores del logo (rosa chicle, cherry y crema) más regaliz; el fondo del hero cambia según la foto de cada diapositiva.
- `assets/main.js`: carrusel del hero, chispas de colores, menú móvil y carrito de demostración. Pon el número de la tienda en `WHATSAPP` para activar los enlaces.
- `assets/fonts/`: Anton (títulos), Pacifico (script) y DM Sans (texto), licencia OFL.
- `assets/img/`: logo y fotos de demostración de Unsplash. Hay que cambiarlas por fotos propias de los productos.

Para verla en local: `python3 -m http.server` y abre http://localhost:8000.
